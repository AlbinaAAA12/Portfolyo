# Portfolyo

Одностраничное адаптивное портфолио на React, TypeScript и Vite. Главная страница не прокручивается: секции переключаются внутри экрана. Доступны русская и английская версии. Онбординг длится 4204 мс, показывается один раз и автоматически открывает портфолио.

## Локальная разработка

Требуется Node.js 22 и npm.

```sh
npm ci
npm run dev
```

Сборка и локальный просмотр production-версии:

```sh
npm run build
npm run preview
```

## Структура

- `src/components/` — компоненты портфолио, оверлеев и онбординга.
- `src/main.css` и CSS рядом с компонентами — адаптивные стили.
- `public/assets/figma/` — статические изображения и SVG.
- `public/assets/onboarding-reference.mp4` — экспортированный ролик онбординга.
- `public/assets/videos/` — место для оригинальных видео, необходимых исходному shader-режиму онбординга.

В `public/assets/figma/` сохранены изображения и SVG, полученные через Figma MCP, включая отдельные карточки проектов и PNG-постеры для галереи. Ролик онбординга находится в `public/assets/onboarding-reference.mp4`. Список оригинальных видео и их назначение приведены в [ASSETS-NEEDED.md](ASSETS-NEEDED.md). Галерея кейсов пока показывает статичные PNG-постеры; видео кейсов ещё не подключены. Текущий онбординг использует экспортированный MP4; исходный WebGPU shader-режим отключён. Чтобы включить его, добавьте пять перечисленных в документации исходных видео в `public/assets/videos/`, установите `hasCompleteOnboardingSourceMedia` в `src/components/onboarding/source-media.ts` в `true` и проверьте воспроизведение в браузере с поддержкой WebGPU.

Готовый PDF резюме должен находиться по пути `public/assets/resume.pdf`. При сборке Vite включает кнопку скачивания только если файл существует и начинается с корректного `%PDF-` заголовка. Без него кнопка остаётся отключённой.

## GitHub Pages

Workflow `.github/workflows/pages.yml` запускается только вручную через **Actions → Deploy to GitHub Pages → Run workflow**. Он выполняет `npm ci`, `npm run build` и публикует `dist`. Для проекта репозитория `Portfolyo` настроен базовый путь `/Portfolyo/`.

В настройках репозитория откройте **Settings → Pages** и выберите **GitHub Actions** как источник сборки. Сам workflow здесь не запускается. Для публикации GitHub Pages из приватного репозитория GitHub требует подходящий платный тариф; опубликованный сайт обычно доступен публично независимо от приватности исходного репозитория. Проверьте действующие условия в [документации GitHub Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/about-github-pages).

## Примечания

- Приложение статическое: backend и серверное хранилище не используются.
- Исходные видео для shader-режима онбординга пока отсутствуют; точное визуальное совпадение с оригиналом не заявляется.
