# Portfolyo

Одностраничное адаптивное портфолио на React, TypeScript и Vite. Главная страница не прокручивается: секции переключаются внутри экрана. Доступны русская и английская версии. При каждом открытии или перезагрузке страницы онбординг проигрывает один цикл длительностью 4204 мс и открывает экран «Обо мне».

Десктопная сцена сохраняет сетку Figma 1280×832: на больших экранах она центрируется, на меньших пропорционально уменьшается. До 600 px включается мобильная компоновка. В коллаже повторяются кликабельные превью пяти кейсов; при наведении карточка плавно поднимается на 16 px. Пять отзывов переключаются горизонтальной прокруткой и точками. Кейсы Ladder Enjoyers и галереи подробного кейса поддерживают свайпы; вертикальная прокрутка доступна в модальных окнах.

## Локальная разработка

Требуется Node.js 22 и npm.

```sh
npm ci
npm run dev
```

Сборка и локальный просмотр production-версии:

```sh
npm run build
npm run preview
```

## Структура

- `src/components/` — компоненты портфолио, оверлеев и онбординга.
- `src/main.css` и CSS рядом с компонентами — адаптивные стили.
- `public/assets/figma/` — статические изображения и SVG.
- `public/assets/onboarding-reference.mp4` — экспортированный ролик онбординга.
- `public/assets/videos/` — оригинальные видео кейсов, портрета и исходного shader-режима онбординга.

В `public/assets/figma/` сохранены изображения и SVG, полученные через Figma MCP, включая карточки проектов, PNG-постеры, состояния боковой панели и логотипа Spirit. Список оригинальных видео приведён в [ASSETS-NEEDED.md](ASSETS-NEEDED.md). При сборке Vite находит файлы MP4/WebM по указанным именам: после добавления оригиналов и повторной сборки видео автоматически заменяют постеры в кейсах, коллаже и портрете. Они воспроизводятся без звука, автоматически и по кругу; при ошибке загрузки возвращается постер. Пока оригиналы отсутствуют, показываются изображения без запросов к несуществующим роликам.

Текущий онбординг использует экспортированный через Figma MCP `public/assets/onboarding-reference.mp4`. Исходный WebGPU shader-режим отключён. Чтобы включить его, добавьте пять перечисленных в документации исходных видео в `public/assets/videos/`, установите `hasCompleteOnboardingSourceMedia` в `src/components/onboarding/source-media.ts` в `true` и проверьте воспроизведение в браузере с поддержкой WebGPU. При системном уменьшении движения заставка остаётся статичной и через 4204 мс открывает «Обо мне».

Готовый PDF резюме должен находиться по пути `public/assets/resume.pdf`. При сборке Vite включает кнопку скачивания только если файл существует и начинается с корректного `%PDF-` заголовка. Без него кнопка остаётся отключённой.

## GitHub Pages

Workflow `.github/workflows/pages.yml` запускается только вручную через **Actions → Deploy to GitHub Pages → Run workflow**. Он выполняет `npm ci`, `npm run build` и публикует `dist`. Для проекта репозитория `Portfolyo` настроен базовый путь `/Portfolyo/`.

Репозиторий публичный, источник публикации в **Settings → Pages** — **GitHub Actions**. Сайт: https://albinaaaa12.github.io/Portfolyo/. Обычный push не запускает публикацию: после изменений нужно вручную запустить workflow.

## Примечания

- Приложение статическое: backend и серверное хранилище не используются.
- Исходные видео для shader-режима онбординга пока отсутствуют; точное визуальное совпадение с оригиналом не заявляется.
