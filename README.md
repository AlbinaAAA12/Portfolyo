# Portfolyo

Одностраничное адаптивное портфолио на React, TypeScript и Vite. На десктопе кейсы прокручиваются внутри фиксированной сцены с перспективным переходом и мягкой остановкой; на телефонах и планшетах используется вертикальная лента. Доступны русская и английская версии. При каждом открытии или перезагрузке страницы онбординг проигрывает один цикл длительностью 4204 мс и открывает экран «Обо мне».

Портрет на главной использует исходное фото и локальную WebGL2-анимацию видимого глаза: взгляд плавно следует за курсором, моргание повторяется через4–7секунд. На устройствах с coarse pointer предусмотрены небольшие самостоятельные движения взгляда. Размеры и кадрирование сохранены; при reduced motion или недоступном WebGL остаётся статичное фото. Новый видеоролик и backend не требуются.

Десктопная сцена сохраняет сетку Figma 1280×832: на больших экранах она центрируется, на меньших пропорционально уменьшается. До 1100 px включается отдельная компоновка с вертикальной прокруткой: профиль, подписанные карточки четырёх кейсов, отзывы и логотипы. В мобильных кейсах сначала показаны заголовок с действием и первое превью, затем описание и теги, после — оставшиеся макеты. Внизу остаётся одна кнопка с названием следующего кейса; возврат к списку доступен сверху. Вместо заметного закреплённого хедера используется незакреплённая строка «Меню / Язык»; отдельное меню содержит только четыре подписанных превью проектов, без заголовка и сегментов. Панель закрывается выбором кейса, нажатием снаружи или Escape. Четыре тега в кейсах собраны в пары с gap8px; три тега Веритас — в горизонтальную прокручиваемую строку без уменьшения текста. Перед списком работ оставлен отступ48px. Контакты и резюме доступны прямо под вступлением. На главной названия и стрелки стоят над превью; отдельный заголовок «Кейсы» убран. Отзывы показаны на белой плашке с padding16px и radius24px; активные и неактивные точки отзывов и подробных галерей имеют размер6px и одинаковый шаг24px. Логотипы движутся одним медленным рядом внутри белого фрейма. От 701 px карточки проектов идут в два столбца. Коллаж четырёх кейсов бесконечно пролистывается в обе стороны колесом, трекпадом, перетаскиванием и стрелками клавиатуры. Галерея использует диагональный ряд полупрозрачных экранов шириной 480 px с высотой по исходным пропорциям каждого проекта по новому визуальному референсу. При наведении карточка плавно поднимается на 64 px, сохраняя перспективу, а остальные смещаются от неё по диагонали. Выбранное видео становится почти непрозрачным; рамка прилегает к медиа без пустых полей. В покое opacity равна .88, у выбранного экрана — .99. Переход занимает 650 мс и плавно возвращается при уходе указателя. Колесо использует короткое сглаживание через requestAnimationFrame без инерции скорости; во время прокрутки hover сбрасывается и не возвращается под неподвижной мышью. В ряду16 стабильных слотов: невидимые карточки переносятся индивидуально за границей панели, выбранная карточка сохраняет физический слой. Для drag и стрелок сохраняется полная дистанция ввода. Пока доступен один отзыв Кристины, руководителя ООО «Веритас», с иконкой Веритас в прежнем сером цвете. Остальные отзывы и пагинация временно скрыты; русский текст и английский перевод доступны в обеих компоновках. Галереи подробного кейса поддерживают свайпы; на десктопе вертикальная прокрутка доступна в модальных окнах, на мобильных также в общей ленте.

Логотипы в нижней полосе открывают соответствующие кейсы: Т-Банк и Spirit — Spirit LBaaS, Ladder Enjoyers — ИИдеи Будущего, Мозг.лаб и Веритас — свои страницы. Hover и keyboard focus розовые; Spirit сохраняет подмигивание. На мобильных остаётся медленная бегущая строка; при клавиатурном фокусе она превращается в статичный прокручиваемый ряд.

Desktop-кейсы используют нативный вертикальный scrollport под неподвижным хедером. Два блока движутся вместе с перспективным наклоном; после остановки прокрутка мягко доводится к ближайшему кейсу. Индикаторы свёрнутой боковой панели плавно меняют длину и цвет: текущий14px/#202124, остальные6px/#B3B4B8. Модальные окна блокируют прокрутку кейсов; reduced motion отключает перспективу и пружинное сглаживание.

Primary-навигация использует обновлённый вариант Figma UI / Link / Primary: розовый hover и новая SVG-стрелка только у невыбранных кнопок,300ms ease-in-out. Выбранная кнопка сохраняет чёрный фон и белую стрелку. Переключатель языка и состояния боковой панели соответствуют актуальным UI / Header, Component 24 и Component 11. Статичный макет Spirit использует оригинальное SVG-пустое состояние с векторным текстом и точно заданным crop исходного backdrop. В левых описаниях кейсов RU/EN нет конечных точек.

## Локальная разработка

Требуется Node.js 22 и npm.

```sh
npm ci
npm run dev
```

Сборка и локальный просмотр production-версии:

```sh
npm run build
npm run preview
```

## Структура

- `src/components/` — компоненты портфолио, оверлеев и онбординга.
- `src/main.css` и CSS рядом с компонентами — адаптивные стили.
- `public/assets/figma/` — статические изображения и SVG.
- `public/assets/onboarding-reference.mp4` — сохранённый видеореференс из Figma; в интерфейсе используется живая анимация.
- `public/assets/videos/` — облегчённые MP4 семи роликов кейсов, предоставленных владельцем.

В `public/assets/figma/` сохранены изображения и SVG, полученные через Figma MCP, включая карточки проектов, PNG-постеры, состояния боковой панели и логотипа Spirit. В резюме скачивание оформлено компактной ссылкой с иконкой слева. Пока `public/assets/resume.pdf` отсутствует, ссылка недоступна; существующая проверка PDF включит её при добавлении файла.

Семь предоставленных роликов подключены в кейсах, коллаже и анимации резюме. Они воспроизводятся без звука, автоматически и по кругу; при ошибке загрузки возвращается постер. Коллаж начинает загружать видео после онбординга, а отдельные превью — после первого появления в видимой области. Скрытые ролики и ролики в неактивной вкладке ставятся на паузу; при возвращении воспроизведение продолжается. Для публикации подготовлены H.264 MP4 номинальной шириной 1088 px с исходной длительностью и пропорциями, без звука и с faststart: суммарно 25,9 МБ вместо 659,4 МБ. Оригиналы не изменены. Список файлов и оставшихся медиа приведён в [ASSETS-NEEDED.md](ASSETS-NEEDED.md). При сборке Vite автоматически находит MP4/WebM по указанным именам; после добавления файлов работающий dev-сервер нужно перезапустить.

Онбординг использует восемь живых слоёв с Lens distortion из Figma. Авторский WGSL выполняется через WebGPU; для WebGL2 перенесены те же формулы lateral-режима, 48 выборок ядра и 4 jitter-выборки. Параметры: distortionStrength 0.429999977350235, aberrationStrength 0.1899999976158142, centre 50/50, chromaticMode 0, quality 0. Четыре слоя используют подключённые видео; для слоя 03 1 пока используется полученный через MCP постер. Эффект сохраняется и при отсутствии видео. Анимация стартует после подготовки первых кадров и длится 4204 мс; предусмотрен предельный срок подготовки 6 секунд. При системном уменьшении движения заставка остаётся статичной и через 4204 мс открывает «Обо мне».

Готовый PDF резюме должен находиться по пути `public/assets/resume.pdf`. При сборке Vite включает кнопку скачивания только если файл существует и начинается с корректного `%PDF-` заголовка. Без него кнопка остаётся отключённой.

## GitHub Pages

Workflow `.github/workflows/pages.yml` запускается только вручную через **Actions → Deploy to GitHub Pages → Run workflow**. Он выполняет `npm ci`, `npm run build` и публикует `dist` с базовым путём `/`.

Исходники проекта хранятся в GitHub; источник публикации в **Settings → Pages** — **GitHub Actions**. Сайт: https://atimofeeeva.ru/. Обычный push не запускает публикацию: после изменений нужно вручную запустить workflow. Настройка DNS для домена и HTTPS выполняется отдельно.

## Примечания

- Приложение статическое: backend и серверное хранилище не используются.
- Коллаж в Figma является одним растровым изображением. Интерактивная композиция восстановлена с превью четырёх текущих кейсов; отдельной геометрии карточек исходный файл не содержит.


## Мобильное UX и локальный редактор

Текущая мобильная компоновка, анализ референсов и источники описаны в [MOBILE-UX-V2.md](MOBILE-UX-V2.md); первая итерация сохранена в [MOBILE-UX-REVIEW.md](MOBILE-UX-REVIEW.md). Итоговая проверка — в [design-qa.md](design-qa.md). Тексты RU/EN, медиа, палитра и базовые desktop-стили сохранены.

Visual Truth 1.3.0 запускается только в режиме `npm run dev`, через отдельный lazy DEV-модуль. В production UI и CSS редактора отсутствуют. Его bundled-зависимость хранится в `tools/visual-truth-1.3.0.tgz`, поэтому `npm ci` воспроизводим в GitHub Actions. Редактор позволяет проверять Desktop / iPad / Phone, временные визуальные правки и Make It Code; текущая адаптация реализована в компонентах и CSS, список generated patches пуст.
