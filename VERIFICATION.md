# Проверка первой версии

Проверено 22 октября 2026 года в Chromium (Microsoft Edge).

- `npm run build`: TypeScript и production-сборка Vite проходят.
- Production-сборка открывается с базовым путём `/Portfolyo/`; ошибок приложения и ответов HTTP 4xx/5xx при проверке нет.
- Пять кейсов × два языка × четыре размера (1280×832, 390×844, 320×568, 844×390): 40 сочетаний без прокрутки страницы, наложения описания на теги и выхода шапки за экран.
- Коллаж: переход клавиатурой и перетаскиванием; открывается кейс выбранной карточки.
- Spirit: постоянные замок и «По запросу». У остальных незавершённых кейсов доступна розовая подсказка; подробное окно открывает Мозг.лаб.
- В подробном кейсе переключаются все четыре галереи. Оба окна прокручиваются, закрываются по Escape и кнопкой; кнопка закрытия доступна внизу длинного содержимого.
- Резюме: русский и английский текст, масштабирование декоративной анимации на телефоне, отсутствие горизонтального переполнения.
- Онбординг: один цикл, переход к портфолио после воспроизведения; проверены задержка загрузки и системное уменьшение движения.
- Без готового PDF скачивание отключено. Проверка наличия PDF выполняется при сборке.

Ожидаются готовый PDF и оригинальные видео из `ASSETS-NEEDED.md`. До их получения используются экспортированный через Figma MCP ролик онбординга и статичные превью кейсов. Исходный WebGPU-режим с отдельными видео пока отключён и требует отдельной визуальной проверки после подключения оригиналов. Публикация GitHub Pages ещё не выполнялась.
