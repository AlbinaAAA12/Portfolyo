# Проверка правок по Figma

Проверено 22 октября 2026 года в Chromium (Microsoft Edge).

- `npm run build`: TypeScript и production-сборка Vite проходят.
- Production-сборка открывается с базовым путём `/Portfolyo/`; ошибок приложения и ответов HTTP 4xx/5xx у ресурсов приложения при проверке нет.
- Пять кейсов × два языка × четыре размера (1280×832, 390×844, 320×568, 844×390): 40 сочетаний без прокрутки страницы, наложения описания на теги и выхода шапки за экран.
- Геометрия «Обо мне»: при 1280×832 обе панели 592×584, зазор 16, логотипы 1200×68. При 1920×1080 сцена остаётся 1280×832 и центрируется; при 1024×768 пропорционально масштабируется до 1024×665,6.
- Коллаж: 15 одинаковых карточек 400×250 с повторением пяти текущих кейсов. При hover вертикальный сдвиг −16 px, коэффициенты матрицы перспективы не меняются; уход указателя возвращает карточку. Проверен переход кликом и клавишей Enter, дополнительных кнопок нет.
- Отзывы: пять слайдов; горизонтальная прокрутка колесом и выбор пятой точки работают, активная точка обновляется, страница остаётся неподвижной.
- Ссылки ТГ/почты при hover становятся `#f538a0`. В полосе логотипов нет ссылок и кнопок; Spirit переключается на розовый вариант с подмигиванием из Figma.
- Боковая панель: разворачивается до 48×180, выбор Мозг.лаб открывает кейс и сразу сворачивает панель. Активное состояние Ladder Enjoyers сохраняется и для аутсорс-проекта.
- Spirit: постоянные замок и «По запросу», правая панель использует экспортированную через MCP иллюстрацию пустого состояния с исходной типографикой и тенью.
- Подсказки: RU/EN при 320, 390 и 1280 px — скругление 100, центр совпадает с центром кнопки, зазор 8 px, текст помещается в окно, кнопка не смещается при hover.
- Кнопка Мозг.лаб при hover становится розовой, окно открывается только по нажатию. Все четыре галереи переключаются свайпом по изображению; проверены также стрелки клавиатуры.
- Ladder Enjoyers: реальное перетаскивание мышью по изображению переключает оба проекта в обе стороны. Touch-свайп проверен через Chromium CDP на 390×844; вертикальной прокрутки страницы нет. Сохраняются две кнопки-точки.
- Обе модалки × два языка × три размера (1280×832, 390×844, 320×568): 12 сочетаний без горизонтального переполнения, с вертикальной прокруткой и доступной кнопкой закрытия. Проверены Escape и закреплённое закрытие внизу длинного содержимого.
- Резюме RU на десктопе: ширина 900, высота 3147,92 (фрейм Figma 3148), высоты трёх блоков опыта 421/443/553, образование 330, декоративная сцена 900×900 на белом фоне. Текст защищён от висячих коротких предлогов и союзов неразрывными пробелами.
- Онбординг: показывается после каждой перезагрузки даже при старом флаге в localStorage; MP4 без loop проигрывает один цикл и открывает «Обо мне». При системном уменьшении движения статичная заставка также показывается 4204 мс.
- Рамки медиа: скругление 20, бордер 1 px `rgba(0,16,36,.12)`, тень `0 5px 20px rgba(32,33,36,.1)`. Механизм видео проверен изолированным тестовым перехватом с существующим MP4: autoplay/muted/loop/playsInline включены, время воспроизведения растёт, при ошибке возвращается PNG. Тестовый ролик не добавлялся к проектным видео и не попадает в публикацию.
- Без готового PDF скачивание отключено. Проверка наличия PDF выполняется при сборке.

Ожидаются готовый PDF и оригинальные видео из `ASSETS-NEEDED.md`. До их получения используются экспортированный через Figma MCP ролик онбординга и статичные превью кейсов. Исходный WebGPU-режим с отдельными видео пока отключён и требует отдельной визуальной проверки после подключения оригиналов.
