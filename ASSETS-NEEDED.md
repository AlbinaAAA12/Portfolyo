# Медиа для Portfolyo

Источник: https://www.figma.com/design/ngodoFRwbYo2LClGrPbitG/Portfolyo?node-id=0-1

В `public/assets/figma` находятся изображения и SVG, экспортированные через Figma MCP, семь отдельных изображений карточек кейсов и семь PNG-постеров галереи. Файл `8a88c.jpg` получен как JPEG и сохранён с корректным расширением.

23 октября 2026 года владелец предоставил семь роликов кейсов. Они подключены в `public/assets/videos`, автоматически воспроизводятся без звука и по кругу. Для сайта подготовлены облегчённые H.264 MP4 с faststart и шириной 1088 px; длительность и пропорции сохранены. Исходные файлы не изменены. Суммарный объём копий для сайта — 25,9 МБ вместо 659,4 МБ исходников.

Экспортированный видеореференс онбординга сохранён в `public/assets/onboarding-reference.mp4`. Интерфейс использует живые слои, авторские треки на 4204 мс и Lens distortion. Исходный WGSL из Figma имеет параметры: distortionStrength 0.429999977350235, aberrationStrength 0.1899999976158142, centre 50/50, chromaticMode 0, quality 0. Для браузеров без WebGPU есть WebGL2-реализация тех же формул.

Готовый PDF резюме положить в `public/assets/resume.pdf`.

## Подключение дополнительных медиа

Никаких дополнительных флагов для видео и Lens distortion не требуется. Vite определяет наличие файлов при запуске и сборке. При отсутствии или ошибке ролика остаётся постер, а в онбординге к нему также применяется Lens distortion. Четыре из пяти видеослоёв онбординга используют те же MP4, что и кейсы; слой 03 1 пока показывает отдельный PNG из MCP.

При сборке проверяется PDF-заголовок `%PDF-`; если файла `public/assets/resume.pdf` нет или заголовок не распознан, кнопка скачивания отключена.
